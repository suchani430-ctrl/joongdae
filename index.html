카카오 지도는 JavaScript 키와 도메인 등록이 모두 맞아야 표시됩니다. 한 번 입력하면 이 브라우저에 저장됩니다.

지금 이 페이지 주소
-
카카오 개발자 콘솔 > 플랫폼 > Web > 사이트 도메인에 등록할 값
-
키 발급 · 도메인 등록 방법
  1. developers.kakao.com 로그인 → 애플리케이션 추가하기
  2. 앱 선택 → 좌측 앱 키 → JavaScript 키 복사 (REST API 키·네이티브 앱 키로는 지도가 열리지 않습니다)
  3. 좌측 플랫폼 → Web 플랫폼 등록 → 위 값을 사이트 도메인에 입력 → 저장
